# Planches design

Maquettes de référence de l’application. Le thème (`lib/core/theme/`) et les
visuels (`assets/images/`) en sont dérivés ; toute évolution d’écran doit
rester cohérente avec ces planches.

| Fichier | Contenu | Profil |
|---|---|---|
| `planche-1-citoyen-onboarding-accueil.jpg` | Écran de bienvenue, inscription téléphone + code à 6 chiffres (choisi par l'utilisateur, sans SMS), accueil, palette et pictogrammes | Citoyen |
| `planche-2-citoyen-signalement-collecte-carte.jpg` | Signaler une décharge, demande de collecte, carte des points | Citoyen |
| `planche-3-citoyen-recompenses-profil-historique.jpg` | Récompenses et niveaux, profil, historique | Citoyen |
| `planche-4-backoffice-municipal.jpg` | Tableau de bord, signalements, zones et opérateurs, rapports | Municipalité (desktop) |
| `planche-5-collecteur-accueil-tournee.jpg` | Accueil collecteur, tournée du jour, détail d’un arrêt | Collecteur |
| `planche-6-collecteur-confirmation-revenus.jpg` | Confirmation de collecte, historique, revenus | Collecteur |
| `planche-7-suivi-detail-notifications.jpg` | Détail d’un signalement, suivi d’une demande, notifications | Citoyen |

Palette : vert `#2E7D32`, vert clair `#A5D6A7`, ocre `#D9A441`, fond `#F8F7F1`,
texte `#4A4A4A`. Typographie : Poppins (titres) et Inter (corps).

`sources/` contient les visuels bruts générés pour l'app avant recadrage ;
`app_icon_preview.png` est l'icône d'application finale (1024 px).
